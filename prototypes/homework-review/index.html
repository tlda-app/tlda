Official solution

callout-solution week=7

Suppose mu(0) = 0.6 and mu(1) = 0.7, so the true difference is 0.1. With nprior = 10 and N0 = N1 = 200, compare same-prior and different-prior regularization.

Choice 1: Same prior, thetaprior = 0.5

Both biases are negative. Both group means get pulled down toward 0.5.

bias[mu_tilde(0)] = 10(0.5 - 0.6) / 210 = -0.0048 bias[mu_tilde(1)] = 10(0.5 - 0.7) / 210 = -0.0095

The bias of the difference is -0.0095 - (-0.0048) = -0.0048. Both means got pulled down, so the difference barely changed.

Choice 2: Different priors

The biases go in opposite directions. Group 0 gets pulled up, group 1 gets pulled down.

bias[mu_tilde(0)] = 10(0.7 - 0.6) / 210 = +0.0048 bias[mu_tilde(1)] = 10(0.5 - 0.7) / 210 = -0.0095

The bias of the difference is -0.0095 - (+0.0048) = -0.0143. The estimated difference got squeezed from both sides.
