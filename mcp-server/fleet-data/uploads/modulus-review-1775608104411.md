### Issue 1: What is the R script actually computing for δ\_max?

The text says: **δ\_max(B) = largest δ where Cr² + ε(B)·δ ≤ n^{-1/2}**.

That's a simple formula: δ\_max = (n^{-1/2} - Cr²) / ε(B).

The R script computes: **largest δ where ω(δ) + ε(B)·δ ≤ n^{-1/2}**.

These are different things. ω(δ) is the actual centered empirical process (computed numerically). Adding ε·δ to it doesn't correspond to any theorem — the bound says ω(δ) ≤ Cr² + ε·δ, not ω(δ) + ε·δ ≤ something. The script appears to double-count the centering error: ω(δ) already captures it (it's the supremum of the centered process), and then ε·δ is added on top.

**Options**:
- (a) Plot δ\_max from the bound: (n^{-1/2} - Cr²)/ε(B). Requires computing Cr² from the model's eigenvalues.
- (b) Plot where the actual ω(δ) hits n^{-1/2}. This doesn't depend on B at all.
- (c) Something else?

The current plot looks qualitatively right (δ\_max increasing in B, models behave differently), but the formula doesn't match any theorem I can identify.

### Issue 2: The sufficiency condition

Line 1357 now says: "it suffices that Cr² + ε(B)·δ\* = o(n^{-1/2})."

This is correct but a bit circular — it's just restating the bound. The more informative statement is: r² = o(n^{-1/2}) (which is about the model complexity relative to n) and ε(B)·δ\* = o(n^{-1/2}) (which is about approximability). These are different conditions with different content.

For the nonparametric case: ε(B) → 0 as B → ∞, so ε·δ\* → 0. But what about Cr²? r is the critical radius for the model — does it go to zero? For a fixed model, r depends on n and goes to zero as n → ∞ at a model-dependent rate. So Cr² = o(n^{-1/2}) is really a condition on the model complexity relative to n.
