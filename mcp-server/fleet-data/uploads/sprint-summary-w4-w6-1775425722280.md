## W6 — Esc Interrupt Shortcuts

### What changed

**`FleetChatShape.tsx` — chat input keydown handler**

New behavior on the chat textarea:
- **Esc on empty input (once)** → soft interrupt: `POST /api/send-key { agent, key: 'Escape' }`
- **Esc on empty input (twice within 500ms)** → hard interrupt: `POST /api/interrupt { agent }`
- Esc on non-empty input: no change (normal browser behavior)

Implementation note: uses native `addEventListener('keydown')` rather than React `onKeyDown` — tldraw's capture-phase `stopEventPropagation` blocks synthetic Escape events, so native listener is required.

Targets the agent currently filtered in the chat shape (from the `filter` prop).
