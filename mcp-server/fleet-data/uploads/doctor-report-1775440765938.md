## New checks added

### Check 3b: SPA serves pages

Not just "is port 5176 open" — fetches `GET /` with the auth token and checks the response contains `<div id="root">` (the React app mount point). Catches cases where the server is running but the SPA bundle is missing, stale, or serving 404s.

### Check 3c: Bundle freshness

Compares `dist/index.html` mtime against the latest git commit touching `src/`, `vite.config.ts`, `index.html`, or `package.json`. If the bundle is older than the latest source commit, warns with "Bundle is stale" and suggests `npm run build`.

If `dist/index.html` doesn't exist at all, it's an error.

## What's NOT implemented

**Auto-fix (rebuild + restart)** — the task mentioned offering to rebuild when SPA is down. Currently the doctor reports the problem with a fix hint (`npm run build`). Full auto-fix would require interactive confirmation and a 10+ second build. Could add `tlda doctor --fix` as a follow-up.
