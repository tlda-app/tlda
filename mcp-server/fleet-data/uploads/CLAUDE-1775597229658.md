# The Balancing Act in Causal Inference

LaTeX manuscript on balancing weights for causal inference. **Biometrika** submission.

## Biometrika Style

### Bracket nesting order
`[ { ( ) } ]` — parentheses innermost, then braces, then square brackets.

### Expectation, Variance, etc.
Operators take whatever bracket fits the nesting context:
- Outermost: `\Var(...)`
- Inside parens: `\E[...]`
- Inside both: `\Var\{...\}`

### Other conventions
- `var` not `Var`, `cov` not `Cov`, `pr` not `Pr`, `tr` not `trace`
- `E(X)` style, not `EX`
- `log x` not `ln x`
- Avoid `\sqrt{}`; use `(abc)^{1/2}`
- No multiple overbars
- Write `a/(bc)` not `a/bc`

## Submission Strategy

Biometrika **synthesis paper** track (new format). 31pp main + 17pp supplement in bka format.

If editor pushes back on length:
- First line of defense: trim Sobolev details, symmetrization walkthrough, move TMLE and invariance remarks to supplement (~3–4pp savings). See `scratch/trimming-options.md`.
- If they want the matching section (Sec 6) cut: propose splitting into a synthesis paper (without matching) + a separate **short paper** (bka 8pp format) on the matching/rounding results. Better for paper count, and the matching contribution arguably stands on its own. But we prefer keeping it unified.
- Originality is less critical for synthesis track, so the paper works without the matching section as a pure synthesis — but the matching section is the most original piece and ties the narrative together.
