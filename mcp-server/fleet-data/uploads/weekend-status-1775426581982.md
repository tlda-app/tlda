## 1. VOICE

### Promised
- Voice recording that works reliably: say stuff, edit, keep talking, hit Enter, clean slate
- Auto-recovery when Chrome's speech API silently dies

- Research: 3 working whisper implementations found, root causes documented

- **Message duplication still occurs.** In-flight whisper response returns after Enter and fills textarea with just-sent text. NOT FIXED ON MAIN.
- **Longer messages vanish.** Reported by Skip today — text disappears during longer dictation. NOT INVESTIGATED.
- **Old messages get injected.** Reported by Skip today — previous message text appears in current textarea. NOT FIXED.
- **Chat switching breaks state.** Clicking into a different agent's chat corrupts voice state. NOT INVESTIGATED.
- **3-second audio segmentation.** voice-fixer was segmenting audio into 3s blobs for whisper instead of sending full accumulated audio. Skip: "THINK I BREAK MY SPEECH INTO 3S BLOBS?"
