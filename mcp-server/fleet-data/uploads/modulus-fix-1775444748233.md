# Modulus definition fix

## What's wrong (line 1358–1361)

Current definition:
$$\omega(\delta) = \sup\left\{|\mathbb{E}(m_1(X)) - \mathbb{E}(m_2(X))| : m_1, m_2 \in \mathcal{M},\; \|m_1 - m_2\|_{L_2(P)} \le \delta\right\}$$

Problems:
1. Uses population $P$ — should be empirical $P_n$
2. Two-point form (pairs $m_1, m_2$) — the Bregman paper uses one-point penalized form
3. Parameterized by $\delta$ (ball radius) — doesn't match the bias formula $\omega(s) - \omega'(s)s$ which uses the penalty parameterization

## What the Bregman paper has (appendix line 4128–4129)

$$\omega(s) = \sup_{f \in B_\rho} \psi(f) - s \cdot \chi^*(f/s)$$

For quadratic dispersion $\chi^*(\phi) = \hat{P}\,\phi(Z)^2/2$:
$$s \cdot \chi^*(f/s) = \frac{1}{2s}\hat{P}\,f(Z)^2$$

So:
$$\omega(s) = \sup_{f \in B_\rho} \psi(f) - \frac{1}{2s}\hat{P}\,f(Z)^2$$

## Mapped into this paper's notation

In the $\psi_1$ context, restricted to treated units:

- $B_\rho = \mathcal{M}$ (the model)
- $\psi(m) = \frac{1}{n}\sum_{i=1}^n m(X_i)$ (empirical mean — the functional we're estimating)
- $\hat{P}\,f(Z)^2$ on treated units $= \frac{1}{n}\sum_{W_i=1} m(X_i)^2$

So the modulus is:
$$\omega(s) = \sup_{m \in \mathcal{M}}\left\{ \frac{1}{n}\sum_{i=1}^n m(X_i) - \frac{1}{2sn}\sum_{W_i=1} m(X_i)^2 \right\}$$

**I'm not 100% sure about the $1/n$ vs $1/N_1$ normalization here.** The Bregman paper uses $\hat{P}$ (average over all $n$ observations) but the treated-only pairing might change this. Worth double-checking.

The parameter $s$ relates to the tuning parameter $\sigma$ via $s \propto n/\sigma^2$ — small $\sigma$ (aggressive balance) means large $s$ (cheap penalty), which makes the penalized modulus larger and the bias $\omega(s) - \omega'(s)s$ smaller.

## The bias formula then works

With this definition, the bias of the minimax balancing weights is:
$$\text{imbalance}_{\mathcal{M}}(\hat\gamma) = \omega(s) - \omega'(s) \cdot s$$

at the optimal $s$. When $\omega$ is approximately linear ($\omega(s) \approx c \cdot s$), the bias is approximately zero — same punchline as before, but now the definition and the formula are consistent.

## What the verbal description should say

The current text says: "measures how much the mean $\psi_1$ can change when the underlying function $\mu_1$ changes by $\delta$ in $L_2$ norm."

With the penalized form, it's more like: "measures the worst-case value of the target functional over the model, penalized by the empirical $L_2$ norm of the function on the treated sample." The penalty parameter $s$ controls the bias-variance tradeoff: small $s$ penalizes $L_2$ norm heavily (favoring smooth, small functions), large $s$ lets the norm grow (allowing rougher functions that test balance more aggressively).
