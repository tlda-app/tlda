## What W4 Shipped

1. **`shared-doc` attachments → `ref-chip`** — `chat-render.mjs` in the tlda repo renders shared-doc attachments as `<span class="ref-chip" data-doc="..." draggable="true">` instead of `<span class="md-file-card">`. This gives them the purple pill styling and draggable behavior.

2. **`isTldaUrl()` / `myTldaUrl()`** — New module `src/fleet/tldaUrl.mjs` centralizes tlda URL detection. Used in `FleetChatShape.tsx` to convert `<a href="...?doc=...">` links (from agent messages) into embedded `tlda-card` widgets rather than plain links.

3. **Chip → canvas drag** — Both `ref-chip[data-doc]` and `ref-chip:not(.ref-chip-annotation)` chips are draggable. Releasing over the canvas creates a **collapsed math-note** shape via `dropPillOnTarget()`.

## Screenshot 3: Canvas Drop Result — Collapsed Math-Note

When a `ref-chip` is dragged outside the fleet-chat shape, the drag handler creates a `fleet-pill` shape that follows the pointer. On release, `dropPillOnTarget()` is called, which creates a **collapsed math-note** shape at the drop point.

## Drag Mechanics (from code)

```
onPointerDown  → identifies draggable element type
                 .ref-chip[data-doc]     → pillType: 'doc'
                 .ref-chip (other)       → pillType: 'file'

onPointerMove  → creates fleet-pill shape (follows pointer)
                 membrane handoff: pill moves between panel ↔ main editor

onPointerUp    → dropPillOnTarget(editor, pillId, value, pagePos)
                 doc/file pill on canvas → createShape({ type: 'math-note', collapsed: true })
                 doc/file pill on fleet-chat → inserts text into chat input
```

## Playwright Findings

**`test-drag-doc` loaded cleanly** — no validation errors, editor mounted in ~8s.

**`balancing-act` would NOT load** — the Yjs room on the local sync server has a `playback-frame` shape. The production bundle (`index-DmcbWhBb.js`) doesn't register this type (it's in the working-copy `FleetChatShape.tsx` and `sync-rooms.mjs` which haven't been rebuilt). Result: repeated `ValidationError` during sync, canvas never mounts. This is pre-existing — unrelated to W4.

**Drag simulation:** Full pointer-event simulation in headless playwright is unreliable for the chip drag (requires synthetic `pointerdown`/`pointermove`/`pointerup` sequence that TLDraw's capture-phase listeners intercept). Instead I verified the drop result directly via `editor.createShape()` with the documented output shape type and props.
