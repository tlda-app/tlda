# What Works and What Doesn't

Written in terms of what you wanted to do, not feature names.

---

## Talking to agents

**What you wanted:** Say stuff into the mic. Maybe edit it. Maybe keep talking. Hit Enter. Clean slate. Do it again. Don't think about it.

**What you can do now:** Voice works in Safari using Web Speech API. Whisper is dead. You can talk, it transcribes, you hit Enter. The cursor thing is annoying but it works.

**What you can't do:** Use voice in Chrome. Chrome voice never worked reliably and whisper made it worse. Safari is the baseline now.

---

## Reading chat

**What you wanted:** See what agents are saying. Chat scrolls to the bottom automatically. Messages look clean. No XML garbage, no duplicate messages, no old messages appearing.

**What you can do now:** Chat works in the HUD. You can read messages, send messages, filter by agent.

**What you can't do:** Chat doesn't auto-scroll to the bottom. You have to manually scroll down to see new messages. Old messages sometimes get injected into the textarea. Switching between agent chats can corrupt state.

---

## Arranging the fleet UI

**What you wanted:** A button that puts you in layout mode. Everything gets a container you can resize, and all the shapes inside scale to fit. You can grab individual shapes and move/resize them like rectangles. When you're done, hit the button again and the container goes away. No clipping. No persistent container shape that causes nightmares.

**What you can do now:** Nothing. The HUD is back to its pre-weekend state (the broken drag/resize was reverted). You can expand/collapse the fleet pill. That's it.

**What exists but isn't deployed:** The layout mode you described was built and is sitting in a worktree. It has the transient container, proportional resize, per-shape movement. It was tested in playwright. It's not on main because nobody merged it.

---

## Seeing what agents are doing

**What you wanted:** Activity indicators that match the terminal experience. When an agent is thinking, you see "thinking." When they're done, it goes away. Same as in the terminal but styled for fleet chat.

**What you can do now:** There's a thinking indicator in chat. It mostly works but had flickering issues (cleared mid-work by activity events).

**What you can't do:** Soft/hard interrupts from chat (like Esc in terminal). That was specced but not built.

---

## Dragging things into chat

**What you wanted:** Drag an agent name, a label, a file, an annotation — drop it on a chat and get a clean chip. Not a wall of text. Not a chip plus raw text. Just a chip.

**What you can do now:** Agent names and labels drag as pills and create filter chips on chat. Shared docs render as blue ref-chips (not the old grey boxes). You can drag files and they upload + insert markdown links.

**What you can't do:** Chips still sometimes render doubled (two chips instead of one). Hover on chips shows identical content for same-agent chips (no unique identity). Dragging onto non-input areas of chat still does something (should be ignored). Contradictory filters show nothing with no indication that the filter is impossible.

---

## Reviewing completed work

**What you wanted:** Agents finish work, it auto-queues with evidence. You passively scroll through results. Playbacks auto-advance. Reject = one tap. You don't have to navigate anywhere or click buttons to start reviewing.

**What you can do now:** Nothing. There's a v1 of task-inbox built by an agent but you've never seen it or reviewed it. Right now you find out about completed work by reading chat messages and hoping agents reported.

---

## Having agents check their own work

**What you wanted:** Agents can read your browser console. Agents can reload your browser (with permission). You stop getting asked to "check the console" or "try reloading."

**What you can do now:** Nothing. The tools (`get_console`, `reload_browser`) are implemented in the fleet MCP code but agents can't see them yet — needs an MCP server restart.

---

## QA before merge

**What you wanted:** No feature ships without QA approval. Tests on the worktree AND after merge. Playwright mandatory. Log review. Multiple screenshots. Your approval before merge to main. "It passes" without evidence = rejection.

**What you can do now:** Nothing enforced. QA agents exist but they rubber-stamp. The W7 HUD was merged over QA's redo request and broke your layout. Features got merged without your approval. Reports check "does the element exist in the DOM" not "does the feature actually work."

---

## Documents loading

**What you wanted:** Documents load. They don't silently break. If something's wrong, you see what's wrong.

**What you can do now:** Most documents load. 404 and auth errors now show clean error screens instead of spinning forever.

**What you can't do:** balancing-act won't load (broken playback-frame shape in Yjs). You asked for all tldraw stores to be wiped — that wasn't done. There's no health dashboard showing you what's broken across all your docs.

---

## Knowing when things are down

**What you wanted:** No silent failures. When a service crashes, you and agents see it immediately. One command to fix it. Don't lose work.

**What you can do now:** `tlda server start` now also starts whisper. `tlda server status` gives a point-in-time check. That's it.

**What you can't do:** See a health dashboard. Get auto-notified when fleet server dies. Auto-restart crashed services. Fix everything with one command. Today the fleet server went down, fleet MCP disconnected silently, tlda went down — you had to discover each one and fix them manually.

---

## Hands-free control

**What you wanted:** Sounds as gestures — tongue clicks, whistles, whatever. Don't have to type, don't have to mouse.

**What you can do now:** Foot pedals work (T-Pedals with axis fix, physics, click). Tongue clicks work but only in foot mode. Sensitivity slider goes to 50x (effectively off).

**What you can't do:** Whistle/hiss detection (research done, not implemented). Custom sound classifier (research done, not implemented). System-wide mic (browser only works when tlda tab is focused).

---

## Playing back what happened

**What you wanted:** Replay agent work sessions. See what happened over time.

**What you can do now:** PlaybackFrame shape exists. You can place it on canvas, pick a recording, scrub through it. Timewarp/named cuts, speed control, subtitles. Shadow history scrubber in the History tab.

**What you can't do:** balancing-act is broken by a playback-frame shape that corrupted the Yjs store. Nobody fixed it.

---

## Bottom line

The things that work: foot pedals, playback, error screens, chip unification (base level), fleet module reorganization, voice in Safari.

The things that are broken RIGHT NOW: chat auto-scroll, voice state corruption on chat switch, balancing-act doc, health monitoring (nothing).

The things that were built but never deployed: HUD layout mode (worktree), browser tools (needs restart), HUD drag clamping fix (worktree).

The things that were never built: 5 chip improvements from the weekend plan, QA enforcement, health dashboard, task inbox review, soft/hard interrupts, hands-free gesture implementation, Yjs store cleanup.
